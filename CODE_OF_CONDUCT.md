# Code of conduct

keel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique work rather than people, and leave room for newcomers. Harassment, insults, and personal attacks are not tolerated.

Report unacceptable behaviour to the maintainer through [a private security advisory](https://github.com/navaniharsh31/keel/security/advisories/new) (it reaches the maintainer privately) or by contacting [@navaniharsh31](https://github.com/navaniharsh31) on GitHub. Reports are handled in confidence.
